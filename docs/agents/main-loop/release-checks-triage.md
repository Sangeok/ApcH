## 발견 ① — 실영상 미리보기 기능이 통째로 도달 불가다

`CaptionStyleEditor`의 소비자를 전수 열거하면 **`pages/settings/ui/index.tsx:260` 하나뿐**이고
`sample`(항상 true)·`playUrl={null}`을 고정 전달한다. FEAT-52가 검토 화면 다이얼로그를
삭제하면서 **유일한 비-`sample` 소비자가 사라졌다.**

그래서 다음이 어떤 화면에서도 판정되지 않는다:

- **FEAT-36 「캡션 스타일 실영상 오버레이 미리보기」** — 재생·큐 동기·재생 튐·presign 실패 4줄
- **BUG-13 「캡션 미리보기 크롭을 블러 레터박스로」** — 5줄 전부. 「원본 좌우가 잘리지 않는가」는
  그 항목의 **존재 이유**라고 원장이 적어놨는데, 그 화면이 사라졌다
- FEAT-49·FEAT-45·FEAT-42·FEAT-40의 검토 다이얼로그 줄 4개

**13줄을 `대체(FEAT-52)`로 닫되 "관측 없이 소멸했다 — 확인했다는 뜻이 아니다"를 줄마다 명시했다.**

샘플 모드에서도 유효한 것(폰트 크기 환산 EN·KR, 폰트 적용, 위치, 샘플 크기·줄 길이, 힌트 둘)은
**열어둔 채 설정 화면 기준으로 재앵커**했다 — 실영상 대조가 불가능하므로 생성된 클립과
나란히 놓고 본다.

## 발견 ② — FEAT-55 확인 줄의 기준이 틀렸다

내가 어제 등재한 「실렌더 **회귀 0** — 배포 전과 같은 스타일로 나온다」는 **배포 전이 옳았다고
전제한다.** 그런데 FEAT-41의 「auto 생성 클립이 요청 단위 스냅샷 스타일로 렌더되는가」가
**한 번도 확인된 적이 없다.** 「같다」를 기준으로 보면 처음부터 틀린 상태를 그대로 통과시킨다.

**「설정한 스타일 그대로 나오는가」라는 긍정 판정으로 고쳤다.**

내가 쓴 줄이고, 등재 하루 만에 내 분류가 잡았다.
