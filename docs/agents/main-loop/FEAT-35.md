**MB8을 등가 변이로 판정한 근거**: `0.0`~`36000.0`(10시간) 격자 **360,001개 전수**에서
`g + 0.5 !== roundTenth(g + 0.5)`인 값이 **0건**이다. 같은 범위에서 `g - 0.5`는 존재한다
(`0.4→-0.09999999999999998`, `0.6→0.09999999999999998`, `0.7→0.19999999999999996`) — 그래서 back 폴백만 시험한다.
forward 폴백의 반올림은 도달 가능한 어떤 입력으로도 관측되지 않으므로, 케이스를 더하면 죽지 않는 변이를 쫓게 된다.
이 판정을 계획서 본문에 근거와 함께 적어 다음 패스가 같은 것을 다시 쫓지 않게 했다.

**라운드 3 결론**: 편집 발생 → 클린 패스 아님. 계약에 맞는 브리핑(3항목만)으로 독립 패스 3차 디스패치.
