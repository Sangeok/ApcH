### 판정 — 필수 목록 정정 후 클린 패스

카탈로그의 경로 8 트리거는 「화면 변경이 있으면」이다. BUG-16에는 화면 변경이 없다 — 메인 루프가 「애매하면 넣는다」로
프레임 합성 검사를 경로 8에 얹었는데, 검증자는 트리거가 맞지 않는다는 사유를 적어 보고했다. **이것은 경로 선정이
과했던 것이다**(보드 안내 블록의 신호). 그래서 독립 패스의 필수 목록을 **1·2·3·4·5·7로 정정**한다. 프레임 합성의 실질은
사라지지 않는다 — 메인 루프 라운드 1·2에서 135건(동일 110 · 수정 25 · 불일치 0)을 실행했고, **인수 때 실제 구현 코드로
같은 하니스를 다시 돌린다**(인수 조건 ③의 일부로 기록할 것).

정정된 목록 기준으로 독립 무편집 패스가 전 경로를 실행해 결함 0 → **클린 패스**. 이 정정은 소유자에게 명시적으로 보고한다
(이의가 있으면 경로 8을 백엔드 프레임 합성으로 풀어 쓴 브리핑으로 재디스패치).

**다음 항목부터**: 백엔드 렌더 경로 항목에서는 프레임 합성 검사를 경로 8로 부르지 말고 경로 2(스케치 실행)의 일부로 둔다 —
카탈로그 경로 8은 화면 렌더용이라 독립 검증자가 트리거를 다르게 읽는다.
