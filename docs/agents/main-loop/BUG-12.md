## 라운드 1 — 메인 루프 (2026-10-15, 편집 있음)

스케치를 트리에 임시 적용해 돌리고 되돌렸다(라운드 끝 `git status` 청결 확인). 하니스는 스크래치패드 `bug12/`.

- 경로 1: 「현재 동작」·여집합 목록의 인용 전부를 내용까지 대조했다. 하나가 어긋났다. `src/fsd/pages/pipeline/page.tsx:24`는 없는 경로이고, 실제는 `src/app/(protected)/pipeline/page.tsx:24`다 → 고침.
- 경로 2·3: 블록 4개를 바이트 그대로 추출했다. before 줄 `<TableCell>{row.lastSeenAt.toLocaleString()}</TableCell>`은 1회 일치했다. 적용 뒤 결과:
  - `TZ=UTC npm test` 337/337(76 suite)
  - `tsc --noEmit` EXIT 0, `next lint` 무경고
  - `verify:fsd`·`verify:fsd:final` 통과, `verify:fsd:test` 13/13
- 경로 4: 계획서 정규식을 다시 돌려 결과가 계획서 목록과 같음을 확인했다. 여집합을 넓힌 검색(UTC 아닌 `get*` 게터, `toUTCString`·`toDateString`·`toTimeString`, 날짜 라이브러리, `<time>`, JSX 안 `*At`/`Date` 보간)은 `:236` 하나만 냈다. 전칭이 성립한다.
- 경로 5: 돌연변이 7개가 `TZ=UTC`·`TZ=Asia/Seoul`에서 모두 사멸했다. 심은 것: tz 제거, 로케일 undefined, 로케일 `en-US`, dateStyle·timeStyle 변경, 값 무시, tz Seoul.
- 경로 7: 테스트의 `process.env.TZ` 강제를 빼면 tz 제거 돌연변이가 `TZ=UTC`에서 산다. locale 단언을 빼면 `en-US` 돌연변이가 산다. 장치 둘 다 실제로 필요하다.
- 경로 8: `AdminAnalyticsPage`를 `renderToStaticMarkup`으로 렌더했다.
  - 적용 뒤: TZ가 Seoul·UTC·LA 어느 쪽이든 `Jul 30, 2026, 10:55 PM`이다.
  - 원본: 같은 세 TZ에서 `2026. 7. 31. 오전 7:55:46`·`2026. 7. 30. 오후 10:55:46`·`2026. 7. 30. 오후 3:55:46`로 갈린다. 이 머신이 ko 로케일이라 로케일 의존도 실증됐다.
  - 렌더에서 보이는 형식 변화(초 탈락, 월 약칭)가 계획서에 없었다 → 「못 덮는 범위」에 추가.
- 결함 2건, 둘 다 문서 위생: 경로 오기, 형식 변화 누락.

## 독립 패스 — plan-verifier 1회차 (2026-10-15, 판정 불가)

**메인 루프의 브리핑 계약 위반.** 계약 셋(항목ID·계획서 경로·필수 경로) 말고도 다섯 가지를 실었다. 무수정 제약, 하니스 위치, 트리 청결 보고, 결함 분류 표시, 경로별 증거 요구다. 모두 `plan-verifier.md`에 이미 계약된 요구다. 그밖에 「5·7은 UTC 러너에서도 확인」「8은 `AdminAnalyticsPage`」 같은 초점 안내와 대조원 지정도 실었다. 검증자는 「이 패스는 무소득 판정 자격이 없다」로 시작해 검증을 끝까지 돌렸다.

- 결과: 필수 7경로 실행, 결함 0. 다만 경로 2의 eslint 측면은 미실행이다. 저장소 밖 파일로는 type-aware lint가 돌지 않고, 트리에는 쓸 수 없다(FEAT-60 1사이클과 같은 유보).
- 트리: 검증자는 저장소 파일을 만들거나 고치지 않았다. 메인 루프가 `git status`로 청결을 직접 확인했다.
- 조치: 스크래치패드에 HEAD `9628d37` detached worktree(`wt-verify`, `node_modules` 세 곳 junction)를 만들었다. 기준선은 admin `tsc` 0, `next lint`(`SKIP_ENV_VALIDATION=1`) 무경고, web도 같다. 계약 셋에 실행 환경(worktree 경로)만 더해 새 컨텍스트로 재디스패치했다.
- 교훈: 브리핑에 이미 계약된 요구를 반복하지 않는다. 같은 위반이 BUG-11·FEAT-33에 이어 세 번째다. 같은 시각 보낸 BUG-18 브리핑도 같은 형태다.
