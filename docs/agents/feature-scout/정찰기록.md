### 제안 2건 (순위 없음)

**A. 업로드 시 「이 쇼의 핵심 순간 유형」 구조화 선택** (열거형 다중선택 → 서버 측 고정 프롬프트 조각)

- 1차 제안1과의 차이: 자유 텍스트가 아니라 **열거형 → 고정 조각**이라 검증되고 인젝션 표면이 없다
